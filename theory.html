ML Decoding of First-Order Reed-Muller Codes

Decoding RM(1,m) Codes on the AWGN Channel

While majority logic decoding is highly effective for Reed-Muller codes on binary channels, an even more efficient algorithm exists for decoding first-order Reed-Muller codes, RM(1,m)RM(1,m)RM(1,m), on the Additive White Gaussian Noise (AWGN) channel. This method, based on the Fast Hadamard Transform (FHT), performs Maximum Likelihood (ML) decoding with remarkable speed.

1. Preliminaries: ML Decoding for the AWGN Channel

First, let's establish the model. An RM(1,m)RM(1,m)RM(1,m) code is a linear code of length n=2mn=2^mn=2m and dimension k=m+1k=m+1k=m+1. Its basis functions are the constant monomial 111 and the mmm linear monomials {X1,X2,…,Xm}\{X_1, X_2, \dots, X_m\}{X1​,X2​,…,Xm​}.

To transmit a binary codeword C∈RM(1,m)\mathbf{C} \in RM(1,m)C∈RM(1,m) over an AWGN channel, we must first map its bits to real values. We use the standard bipolar mapping:

  • 0∈F2↦+1∈R0 \in \mathbb{F}_2 \mapsto +1 \in \mathbb{R}0∈F2​↦+1∈R
  • 1∈F2↦−1∈R1 \in \mathbb{F}_2 \mapsto -1 \in \mathbb{R}1∈F2​↦−1∈R.

This converts the binary codeword C\mathbf{C}C into a bipolar vector Cbip\mathbf{C}_{bip}Cbip​. The channel then adds a noise vector N\mathbf{N}N, whose components are independent, identically distributed Gaussian random variables. The received vector Y\mathbf{Y}Y is: Y=Cbip+N.(1) \mathbf{Y} = \mathbf{C}_{bip} + \mathbf{N}. \tag{1}Y=Cbip​+N.(1) The goal of the decoder is to find the most likely transmitted codeword given the received vector Y\mathbf{Y}Y. For the AWGN channel, the Maximum Likelihood (ML) decoding rule simplifies to finding the codeword that maximizes the inner product (or correlation) with the received vector: C^bip=arg⁡max⁡∗c∈C∗bip⟨Y,c⟩ \hat{\mathbf{C}}_{bip} = \arg\max*{\mathbf{c} \in \mathcal{C}*{bip}} \langle \mathbf{Y}, \mathbf{c} \rangle C^bip​=argmax∗c∈C∗bip⟨Y,c⟩ where Cbip\mathcal{C}_{bip}Cbip​ is the set of all 2m+12^{m+1}2m+1 bipolar codewords of the RM(1,m)RM(1,m)RM(1,m) code. A brute-force search is computationally expensive.

2. The Hadamard Matrix

The key to efficient decoding lies in the structure of the Sylvester-type Hadamard matrices, which are defined recursively for orders N=2mN=2^mN=2m:

  • Base Case (m=1m=1m=1): H2=(111−1)H_2 = \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}H2​=(11​1−1​)
  • Recursive Step: H2m=(H2m−1H2m−1H2m−1−H2m−1)H_{2^m} = \begin{pmatrix} H_{2^{m-1}} & H_{2^{m-1}} \\ H_{2^{m-1}} & -H_{2^{m-1}} \end{pmatrix}H2m​=(H2m−1​H2m−1​​H2m−1​−H2m−1​​)

3. ML Decoding via the Hadamard Transform

The Hadamard Transform of a vector Y\mathbf{Y}Y is the matrix-vector product Z=YH2m\mathbf{Z} = \mathbf{Y} H_{2^m}Z=YH2m​. The jjj-th component of Z\mathbf{Z}Z is the inner product ⟨Y,hj⟩\langle \mathbf{Y}, \mathbf{h}_j \rangle⟨Y,hj​⟩. This single operation computes the correlations with all candidate codewords simultaneously.

The Algorithm: Input: A received vector Y\mathbf{Y}Y of length n=2mn=2^mn=2m. Output: The decoded message polynomial f^(X)\hat{f}(\mathbf{X})f^​(X).

  1. Transform: Compute the Hadamard Transform of the received vector Z=YH2m.(7) \mathbf{Z} = \mathbf{Y} H_{2^m}. \tag{7}Z=YH2m​.(7)
  2. Search: Find the index jjj corresponding to the component of Z\mathbf{Z}Z with the largest absolute value over all 2m2^m2m possible indices j=arg⁡max⁡_i∈{0,…,2m−1}∣Zi∣.(8) j = \arg\max\_{i \in \{0, \dots, 2^m-1\}} |Z_i| . \tag{8}j=argmax_i∈{0,…,2m−1}∣Zi​∣.(8)
  3. Decode: Let the binary representation of jjj be (b1b2…bm)(b_1 b_2 \dots b_m)(b1​b2​…bm​). a. The linear part of the polynomial is a^1X1+⋯+a^mXm\hat{a}_1 X_1 + \dots + \hat{a}_m X_ma^1​X1​+⋯+a^m​Xm​, where a^i=bi\hat{a}_i = b_ia^i​=bi​. b. The constant term a^0\hat{a}_0a^0​ is determined by the sign of ZjZ_jZj​. If Zj<0Z_j < 0Zj​<0, then a^0=1\hat{a}_0 = 1a^0​=1. If Zj>0Z_j > 0Zj​>0, then a^0=0\hat{a}_0 = 0a^0​=0.

4. The Fast Hadamard Transform (FHT)

A direct matrix-vector multiplication takes O((2m)2)O((2^m)^2)O((2m)2) operations. The FHT is an efficient algorithm that reduces this complexity to O(m2m)O(m 2^m)O(m2m) by exploiting the recursive structure of the Hadamard matrix.
